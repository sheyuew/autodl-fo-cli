## 本地与 Codex 入口

默认 `bash ./fo` 在本机运行，无需服务器、邀请码、SSH 或浏览器插件。各账号登录状态由自动启动的本地会话进程隔离，密码与 Token 仅在内存。账号名、任务策略/进度和通知记录会保存到当前账号的本机目录。没有活动抢卡任务时空闲 30 分钟退出，活动任务保留进程；会话结束后需重新登录。子命令与 JSON 输出见 [Codex 操作说明](codex.md)，项目级 [AGENTS.md](../AGENTS.md) 提供登录及确认流程。

macOS/Linux 可运行，Windows 使用 WSL；Windows 原生尚未验证。当前不提供电脑本地与实例直接传输。新网盘授权仍需网页，CLI 不自动打开浏览器。原有服务器模式保留在显式 `fo remote`，普通使用无需部署它。

## 配置、报价与确认

修改需先生成当前账号会话内存中的确认计划，两分钟有效、只能执行一次。最终 `yes/no` 前显示实际对象、参数、费用和后果；执行前复查价格、实例状态、主机、镜像和磁盘等适用配置，变化后需要重新确认。网络中断或提交结果未知时，先刷新实际状态，避免重复提交。

新建支持当前所选主机目录内的基础/私有镜像。克隆仅支持当前账号的已关机源实例，默认 `copyDataDisk:false`。镜像会校验芯片、CPU 架构、主机 CUDA 上限和 GPU 架构 CUDA 下限；驱动来自主机，创建请求不能更换它。

数据盘容量分免费部分和额外付费部分：`dataDiskGB`、`--size-gb`/`sizeGB` 均指额外付费部分的目标总 GB，不是总磁盘容量或本次增量。扩容不能低于现有付费容量；预览包含原值、目标、实际增加量、日费和重启要求。普通容器不提供系统盘扩容，本版本也不操作 Pro 系统盘。

总时价由计算时费与存储日费折算组成。数据盘费用可能在关机后继续计收。已扩容数据盘不会阻止普通实例开机，开机时会读取其完整报价。

## 自动抢卡、运行状态与通知

抢卡策略在启动前绑定模式、地区、GPU 型号和数量、镜像或克隆源、额外数据盘、最高总时价、监控时限及次数。原实例开机绑定原实例 UUID 及其现有配置。每次提交都复查当前候选及完整费用，超价或无卡时等待；权限、配额和不兼容配置等需要处理的错误会停止任务。

`accepted`/`submitted` 只代表平台接受请求；任务仅在观察到目标实例实际 `running` 时 `completed`。单任务最多成功一次，任务完成后实例继续运行和计费。时限约束监控过程，不是实例自动关机时间。取消只停止本地任务，已提交的开机或创建不受影响；未知提交结果不会自动重试。

抢卡在本机会话进程后台运行，关闭登录终端、菜单或 `task watch` 均不取消任务。电脑必须保持开机、唤醒及联网。重启后任务记录可查询，旧授权不会恢复，需要重新预览并 `yes/no` 启动新任务；提交过程中重启的任务会保留结果未知提示，先查实例。

任务结束或需要处理时尝试后台桌面提醒，并保存各账号独立的 `notifications` 记录。`task watch TASK_ID` 提供前台终端进度，关闭跟踪后后台任务继续。通知不可用时记录仍可查询，Linux 需要 `notify-send`，WSL 通知需自行配置。

AutoPanel 目录传输、取消和清理仍需要独立登录及确认。跟踪只跟踪开始时队列中的任务，已完成任务看历史；从队列消失不会误报完成。传输由实例与网盘执行，本地断网后已接受的传输继续，本地提醒需在线。

## 验证范围

自动测试使用本地 HTTP 服务、真实 Unix socket 和真实伪终端，覆盖新建/克隆、数据盘扩容、后台任务状态、报价复查、一次性确认、跨账号隔离、重启不恢复授权、结果未知不重试、文件传输及通知。

真实账号仅进行读取和报价预览，不为验证执行创建、克隆、扩容、开关机、释放或删除。新功能的写操作和状态转换通过测试服务验证，不代表真实租卡或扩容已完成。此前单文件资源库通过真实 256 KiB 往返 SHA-256 校验；递归目录、备份盘和大文件仍需后续真实验证。
