## 执行与通知

实例及镜像写操作需先生成服务器内存中的确认计划，计划只在当前账号有效、两分钟过期、只能执行一次。最终 `yes/no` 前显示实际操作对象、参数、费用和必要后果。开机确认后重新读取价格及状态；变化时要求重新确认。网络中断后，先刷新实际状态，避免重复提交。

目录传输、取消和清理需要独立 AutoPanel 登录及确认。跟踪只跟踪开始时队列中的任务；已经完成的任务看历史。任务未出现在后续返回结果中时不会误报完成。桌面通知失败仍输出终端结果。传输在服务器上执行，本地跟踪与提醒需要客户端在线。

## 验证范围

自动测试使用本地 HTTP 服务、真实 Unix socket 和真实伪终端，覆盖一次性确认、跨账号隔离、报价变化、取消不提交、HTTP 方法/参数、结果未知不重试、目录传输和通知结果。

真实账号验证仅做读取和开机报价预览：实例详情、监控、镜像列表及计算/数据盘费用。没有为验证执行开关机、释放、删除或付费操作。目录递归传输目前只经过测试服务验证；此前单文件资源库通过真实 256 KiB 往返 SHA-256 校验。大目录、备份盘与大文件仍需后续真实验证。
