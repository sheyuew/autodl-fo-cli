# 首次使用 HTTP 版本

1. 安装 Node.js 20.17.0 或更新版本和 OpenSSH。macOS/Linux 直接使用，Windows 使用 WSL。
2. 下载仓库源代码，终端进入解压后的目录。
3. 运行 `bash ./fo join`，粘贴管理员提供的完整一次性邀请码。
4. 输入自己的 AutoDL 子账号（完整的 `用户名@主账户ID`）和密码，密码隐藏且不保存。
5. 登录后进入 HTTP 菜单；已有成员升级客户端后执行 `bash ./fo login`，也可运行 `bash ./fo http`。
6. 主菜单选择 `4 AutoPanel`，选择运行中实例，输入该实例 AutoPanel 独立密码。
7. 上传选择 5，下载选择 6；文件用编号选择，整个目录用 `d 编号`。核对路径后输入 `yes/no`。传输提交后用 7 跟踪进度和完成提醒。
8. 返回主菜单，5 是实例管理，6 是镜像管理；执行操作前均需 `yes/no` 确认。

邀请码默认 24 小时有效，首次绑定成员本机公钥；密钥自动生成，无需交换私钥。同一 AutoDL 账号使用自己的连接环境；添加其他账号用新邀请码，已保存账号通过 `bash ./fo switch` 切换。

上传源路径是实例内路径。下载到实例默认工作目录。传输开始后由实例与网盘交互，本地离线后可再次登录查询结果。

当前 HTTP 版本只支持子账号登录，提供实例管理、镜像管理、库存查询、网盘文件/目录传输和完成提醒，暂不支持主账号登录、抢卡、新建/克隆实例、规格/磁盘调整或远程浏览器。已有账号绑定、SSH 接入和邀请码配置保留。会话仅在服务器内存中，服务重启后要重新登录。

排查：`bash ./fo doctor` 检查后端与登录；登录失效用 `bash ./fo login`；AutoPanel 密码错误在子菜单输入 `p`。SSH 密钥或服务器公钥异常时联系管理员核实，不要使用他人的连接配置。
