# 本地首次使用

1. 安装 Node.js 20.17.0 或更新版本。macOS/Linux 可用，Windows 使用 WSL。
2. Clone 仓库并进入目录，无需 `npm install`：

   ```bash
   git clone https://github.com/sheyuew/autodl-fo-cli.git
   cd autodl-fo-cli
   ```

3. 在自己的终端运行 `bash ./fo login`，输入完整子账号 `用户名@主账户ID`，再隐藏输入密码。无需邀请码、服务器或浏览器登录。
4. 运行 `bash ./fo` 进入菜单；或在仓库中打开 Codex，告诉它“查看实例列表”。Codex 遇到登录过期会提示你在终端重新登录。
5. 实例管理选择主菜单 5，镜像管理选择 6。核对对象、参数、费用和后果后输入 `yes/no`。
6. AutoPanel 选择主菜单 4，选择运行中实例并输入它的独立访问密码。上传选择 5，下载选择 6；整个网盘目录用 `d 编号`。传输提交后选择 7 查看进度及完成提醒。

账号密码只在终端输入，不写在 Codex 聊天、命令参数、环境变量或配置文件中。会话进程自动启动，登录状态仅在本机内存；进程空闲 30 分钟后退出，电脑重启或平台会话过期时也需要重新登录。账号名称会保存，便于选择；每个账号的登录与 AutoPanel 会话独立。

```bash
bash ./fo accounts             # 查看已保存账号
bash ./fo login               # 登录另一个账号，或恢复过期会话
bash ./fo switch 完整账号       # 切换当前账号
bash ./fo doctor              # 检查本地会话和登录状态
bash ./fo logout              # 注销当前账号
```

上传源是实例内路径，下载到实例默认工作目录；目前不支持电脑本地与实例直接传输。已授权阿里云盘可传文件和目录；新授权网盘仍需网页完成，本工具不会自动打开浏览器。

本地查询、提交和提醒需要电脑在线。已提交的实例与网盘传输继续由 AutoPanel 执行；离线期间的结果可重新登录后查历史。Linux 桌面提醒需要 `notify-send`，WSL 提醒需要自行配置，通知不可用时仍显示终端结果。

更多命令见 [Codex 操作说明](codex.md)，支持与限制见 [功能清单](features.md)。原有远程部署单独使用 `bash ./fo remote ...`，参考 [服务器说明](server.md)。
