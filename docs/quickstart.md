# 第一次使用

## 你需要准备什么

- 管理员同意为你开通的服务器环境。
- 自己的 AutoDL 主账号或子账号；账号需要具备相应资源权限。
- Node.js LTS 和 OpenSSH。macOS/Linux 直接使用；Windows 在 WSL 中执行下列命令。

## 1. 下载并启动

从仓库 Releases 下载最新版本的 `autodl-fo-cli-v版本号.zip` 并解压。终端进入解压后的 `autodl-fo-cli` 文件夹：

```bash
bash ./fo
```

macOS 可双击 `开始使用.command`。如果双击未启动，在终端运行上面的命令。

## 2. 粘贴一次性邀请码

向管理员领取 `FO1-` 开头的完整邀请码。首次启动直接按提示粘贴。邀请码输入隐藏，程序自动生成本机密钥、绑定个人环境并保存连接，无需了解 SSH 密钥或填写文件路径。

邀请码 24 小时有效，只能首次绑定一台电脑。同机因断网中断可在有效期内用原码重试；换电脑请联系管理员。不要公开邀请码。

## 3. 在终端登录 AutoDL

接入后程序会提示输入 AutoDL 账号和密码。子账号填完整的 `用户名@主账户ID`，主账号填登录手机号。密码隐藏输入且不保存；登录成功后直接进入任务菜单，登录态保存在自己独立的服务器浏览器中。

以后重新登录：

```bash
bash ./fo login
```

遇到验证码、滑块或平台验证时，程序自动打开浏览器。本人完成验证后回终端按 Ctrl+C，程序核对账号并恢复 Fo。也可用 `bash ./fo login-browser` 主动打开浏览器登录。

## 4. 添加和切换账号

```bash
bash ./fo join       # 新账号：粘贴另一个邀请码，再输入账号密码
bash ./fo accounts   # 已保存的账号
bash ./fo switch     # 选择要操作的 AutoDL 账号
```

每个 AutoDL 账号首次添加需要自己的邀请码，服务器环境、登录态和任务保持隔离。切换只改变本地当前操作的账号；其他账号的服务器任务仍运行。

主菜单也提供“切换 AutoDL 账号”和“添加 AutoDL 账号（邀请码）”。

## 5. 发起任务

```bash
bash ./fo
```

在菜单选择“创建抢卡任务”，依次选择模式和参数。最后核对完整预览，输入 `yes` 启动或 `no` 取消，直接回车也取消。

默认开始等待终端/桌面提醒。Ctrl+C 退出等待后服务器仍会继续。重新连接时用 `bash ./fo watch` 继续等待，`bash ./fo notifications` 查看离线记录。

## 常见问题

- **提示未安装 Node.js**：安装官网 LTS 后重新打开终端。无需执行 `npm install`。
- **SSH Permission denied**：确认导入的是分配给自己的连接文件，私钥对应发给管理员的公钥。自备加密密钥先 `ssh-add`。
- **提示服务器公钥变化**：联系管理员核实服务器变更，再导入新的连接文件。
- **登录失效或 Fo 未加载**：先 `bash ./fo doctor`，需要时 `bash ./fo login`。维护重启期间可能短暂出现历史提醒，注意通知时间。
- **桌面没有横幅**：用 `bash ./fo notify-test` 测试系统通知权限与免打扰设置；终端仍可显示结果。WSL 桌面通知需另配。
- **换电脑**：可迁移自己妥善保管的专用密钥，或在新电脑重新生成公钥并请管理员更新；重新导入连接文件。

## 高级：原公钥/连接文件方式

仍支持 `bash ./fo keygen` 生成或查看公钥，交管理员开通后，用 `bash ./fo setup /path/to/your.connection.json` 导入。自备密钥用 `--key 路径`；有口令的密钥先 `ssh-add`。配置后严格校验服务器公钥。
