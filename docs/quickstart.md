# 第一次使用

## 你需要准备什么

- 管理员同意为你开通的服务器环境。
- 自己的 AutoDL 主账号或子账号；账号需要具备相应资源权限。
- Node.js LTS 和 OpenSSH。macOS/Linux 直接使用；Windows 在 WSL 中执行下列命令。

## 1. 下载并启动

从仓库 Releases 下载 `autodl-fo-cli-v0.1.0.zip` 并解压。终端进入解压后的 `autodl-fo-cli` 文件夹：

```bash
bash ./fo
```

macOS 可双击 `开始使用.command`。如果双击未启动，在终端运行上面的命令。

## 2. 获取你的接入公钥

首次菜单选择“生成/查看我的接入公钥”。程序会在本机生成一对 Fo 专用 SSH 密钥；再次运行会复用原密钥，不覆盖。

把终端显示的 `ssh-ed25519 ...` 整行公钥和希望使用的英文代号发给管理员。也可以发送显示路径中的 `.pub` 文件。没有 `.pub` 后缀的是私钥，保留在自己电脑。

## 3. 导入管理员连接文件

管理员发回 `你的代号.connection.json` 后，重新运行 `bash ./fo`，选择“导入管理员发来的连接文件”，填写文件路径。默认私钥路径直接回车即可；使用自备密钥时填写自己的路径。

也可直接运行：

```bash
bash ./fo setup /path/to/your.connection.json
```

有口令的自备密钥需先运行 `ssh-add 私钥路径`。配置后程序会严格校验连接文件中固定的服务器公钥。

## 4. 登录自己的 AutoDL

```bash
bash ./fo login
```

程序打开你的独立远程浏览器。在官方 AutoDL 页面登录，完成后回终端按 Ctrl+C，程序恢复 Fo 任务页面。用户名和密码直接在官方页面输入，连接文件不包含这些信息。

浏览器未自动打开时，终端会打印本机查看地址和临时查看密码，手动在浏览器打开即可；查看期间保持终端运行。

## 5. 发起任务

```bash
bash ./fo
```

在菜单选择“创建抢卡任务”，依次选择模式和参数。最后核对完整预览，输入 `yes` 启动或 `no` 取消，直接回车也取消。

默认开始等待终端/桌面提醒。Ctrl+C 退出等待后服务器仍会继续。重新连接时用 `bash ./fo watch` 继续等待，`bash ./fo notifications` 查看离线记录。

## 常见问题

- **提示未安装 Node.js**：安装官网 LTS 后重新打开终端。无需执行 `npm install`。
- **SSH Permission denied**：确认导入的是分配给自己的连接文件，私钥对应发给管理员的公钥。自备加密密钥先 `ssh-add`。
- **提示服务器公钥变化**：联系管理员核实服务器变更，再导入新的连接文件。
- **登录失效或 Fo 未加载**：先 `bash ./fo doctor`，需要时 `bash ./fo login`。维护重启期间可能短暂出现历史提醒，注意通知时间。
- **桌面没有横幅**：用 `bash ./fo notify-test` 测试系统通知权限与免打扰设置；终端仍可显示结果。WSL 桌面通知需另配。
- **换电脑**：可迁移自己妥善保管的专用密钥，或在新电脑重新生成公钥并请管理员更新；重新导入连接文件。
