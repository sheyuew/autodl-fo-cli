# AutoDL 本地 CLI

在自己的电脑上管理 AutoDL 子账号、实例、镜像、库存，以及 AutoPanel 网盘传输；支持自动抢卡、新建/克隆普通实例和数据盘扩容。直接通过 HTTP 访问 AutoDL，无需另搭服务器、邀请码、SSH 接入、浏览器插件或开发者 Token。

可以自己用终端菜单，也可以 clone 后在目录里打开 Codex，直接描述需要的操作。仓库中的 [AGENTS.md](AGENTS.md) 和 [Codex 操作说明](docs/codex.md) 会引导它使用子命令和 JSON 输出；账号密码由本人在终端隐藏输入。

## 开始使用

需要 Node.js 20.17.0 或更新版本，无需 `npm install`。macOS/Linux 可运行；Windows 请使用 WSL，尚未验证 Windows 原生运行。

```bash
git clone https://github.com/sheyuew/autodl-fo-cli.git
cd autodl-fo-cli
bash ./fo login
bash ./fo
```

登录输入自己的完整子账号 `用户名@主账户ID`。密码不回显、不保存。本机会自动启动只供当前用户访问的会话进程，将登录状态保存在内存；后续命令复用该会话。电脑重启、会话进程退出或 AutoDL 登录过期后，重新执行 `bash ./fo login`。没有活动抢卡任务时，会话进程空闲 30 分钟后退出；活动任务会保留后台进程。

多个账号各自登录、保留独立内存会话；`bash ./fo accounts` 查看账号，`bash ./fo switch 完整账号` 切换，`bash ./fo logout` 退出当前账号。保存的账号名称方便下次选择；任务策略、进度和通知也保存在本机，不包含密码或登录 Token。

## 交给 Codex 操作

在此仓库目录中打开 Codex，例如告诉它：

> 查看我的实例和空闲 GPU。

> 把这个实例的 results 目录上传到阿里云盘，先让我确认源路径和目标目录。

Codex 可以直接读取结构化结果。需要登录时，它会提示你在自己的终端运行 `bash ./fo login`；AutoPanel 则需要实例的独立访问密码。**密码只在终端输入，不发到聊天里。**

修改先预览对象、参数、费用与后果，等你回答 `yes/no` 后提交。新建、克隆、开机或扩容报价及配置改变时需要重新预览。自动任务先确认固定策略和最高总时价，再在该范围内寻找库存。查看 [命令与完整操作流程](docs/codex.md)。

## 菜单功能

`bash ./fo`、`bash ./fo local` 和 `bash ./fo http` 均进入本地菜单。

| 输入 | 功能 |
|---|---|
| 1 | 实例列表 |
| 2 / 3 | 地区空闲库存 / GPU 型号 |
| 4 | AutoPanel 文件与传输管理 |
| 5 | 实例详情、连接信息、监控、开关机、重启、定时关机及取消、重命名、保存系统盘镜像、释放实例及数据盘扩容 |
| 6 | 我的镜像：列表、进度、重命名、删除或移除 |
| 7 | 新建/克隆普通按量计费实例，选择主机、卡数、镜像、额外数据盘后报价确认 |
| 8 | 自动抢卡：原实例开机、新建或克隆，查询/取消任务与完成提醒 |

写操作需输入 `yes/no`。普通按量计费实例的开机报价包含计算费和扩容数据盘费用；有扩容数据盘的实例可以开机。主菜单 5 可扩容数据盘，输入的是**额外付费部分的目标总 GB**，不含免费容量；预览会列出原值、目标、增量、日费与重启要求。普通容器系统盘不提供扩容，本版本也不操作 Pro 系统盘。SSH 连接信息默认隐藏密码；释放实例会永久删除系统盘和数据盘，保存镜像只包含系统盘。

### AutoPanel 上传下载

进入主菜单 4，选择运行中实例，隐藏输入 AutoPanel 独立访问密码：

| 输入 | 功能 |
|---|---|
| 1 / 10 | 查询实例目录 / 按编号逐级浏览目录 |
| 2 | 浏览已授权网盘目录 |
| 3 / 4 | 传输队列 / 历史记录 |
| 5 / 6 | 实例文件或目录上传至阿里云盘 / 阿里云盘文件或目录下载至实例 |
| 7 | 跟踪当前队列，终端及本地桌面提醒完成结果 |
| 8 / 9 | 取消传输 / 清理已成功记录，保留文件 |
| p / q | 重新登录 AutoPanel / 返回 |

上传填写**实例内**绝对路径，浏览网盘到目标目录后输入 `s`；下载选择文件编号，整个目录使用 `d 编号`。下载位置是 AutoPanel 默认工作目录，通常为 `/root/autodl-tmp`。核对方向、路径及递归范围后输入 `yes/no`，同名目标会拒绝提交。

这里的传输是 **AutoDL 实例 ↔ 已授权阿里云盘**，尚未接入电脑本地 ↔ 实例直接传输。首次授权网盘仍需网页完成，CLI 不会自动打开浏览器。

## 自动抢卡与通知

主菜单 8 可选择原实例开机、新建或克隆。新建/克隆支持地区和 GPU 型号多选，输入 `1,3` 或 `all`，在所选范围内持续寻找主机，无需绑定某一台主机。地区之间、GPU 型号之间分别是“满足任意一个”，卡数是同一台主机上的数量；每个任务最多成功获取一个实例。原实例开机仍绑定它的原主机，需跨主机时使用克隆模式，克隆源要先关机。

数据盘可选“固定额外付费容量”或“最低总容量”。例如总容量至少 900 GB，主机免费 100 GB 时请求付费扩容 800 GB；主机容量不足就跳过，当前全部不满足则继续等待。自动任务无需选择参考主机，创建镜像会对实际候选逐一验证；容量与兼容性最终仍由平台校验，查询不会预留库存。

确定地区、GPU 型号/数量、镜像或克隆源、数据盘策略、**最高总时价**、监控时限及次数，再输入 `yes/no`。最高总时价包含计算费与存储日费折算；每次提交前复查完整报价，按接口返回顺序选择第一个满足条件且预算允许的主机。实例实际进入 `running` 才报告完成。克隆默认仅拷贝系统盘；拷贝数据盘需明确选择，目标容量不得小于源盘容量，源实例保留。

登录终端和菜单可以关闭，抢卡任务在本机后台继续。**电脑必须保持开机、唤醒和联网**；电脑或后台进程重启后只保留任务记录，付费授权不会恢复，需要重新预览和确认。监控时限约束寻找/检查过程，不会在到期后自动关闭已租到的实例；使用完请自行关机，扩容盘仍按平台规则计费。

```bash
bash ./fo task list --json
bash ./fo task watch TASK_ID       # 前台显示进度；关闭不取消后台任务
bash ./fo notifications --json     # 查看各账号自己的通知记录
```

任务完成、失败或需要处理时，后台尝试发送本地桌面提醒并保留通知记录。取消任务会停止本地监控，已经提交的创建/开机请求仍需查询实际状态。遇到“提交结果未知”时任务停止提交；先查实例，不自动重试。

## 运行范围

你的电脑及网络需要在线，才能查询、提交操作和跟踪提醒。已经被 AutoPanel 接受的传输由实例与网盘继续执行，本地离线后可重新登录查看历史。关闭进度跟踪不会取消传输；也不会在离线期间提供桌面提醒。

当前支持子账号与普通按量计费容器；主账号登录、Pro、包卡、GPU 规格调整和计费转换尚未接入。子账号权限由 AutoDL 验证。功能、接口来源和实测边界见 [功能清单](docs/features.md)。

## 旧服务器部署与开发

原有 SSH 服务器模式保留在显式 `bash ./fo remote ...` 入口，普通本地使用无需配置它。已有管理员和成员参考 [服务器说明](docs/server.md)；更早的 Fo 浏览器任务见 [历史文档](docs/legacy-fo.md)。升级为本地模式不会自动启用旧抢卡任务。

原生 HTTP 实现位于 `native/`。运行检查：

```bash
npm test
npm run test:native
npm run test:terminal
```

接口来自 AutoDL 网页和 AutoPanel 前端，平台变更可能需要更新本工具。
