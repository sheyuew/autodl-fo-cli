# AutoDL HTTP CLI

通过 SSH 让服务器执行 AutoDL 子账号登录、实例管理、镜像管理、库存查询，以及 AutoPanel 网盘传输。当前 HTTP 后端不运行 Chrome，不依赖 Fo 或开发者 Token。

**v0.4.0 已支持实例开关机、重启、定时关机、镜像管理和目录传输。** 当前尚未提供抢卡、新建/克隆实例、规格调整或磁盘扩容。 从旧 Fo 部署切换时需明确停止旧监控并备份；旧任务不会自动转换为 HTTP 任务。

## 成员开始使用

需要 Node.js 20.17.0 或更新版本和 OpenSSH，无需 `npm install`。Windows 当前使用 WSL，尚未做 Windows 原生实测。

```bash
bash ./fo join       # 首次使用：输入管理员提供的一次性邀请码
bash ./fo login      # 已接入：输入自己的 AutoDL 子账号和密码
bash ./fo http       # 进入 HTTP 操作菜单
```

子账号填完整的 `用户名@主账户ID`。登录 HTTP 服务器后保存连接类型，下次运行 `bash ./fo` 可直接进入 HTTP 菜单。现有成员继续使用自己的 SSH 密钥和连接配置，升级客户端后重新登录即可。

登录密码不保存；AutoDL 会话仅保留在服务器内存，服务重启或会话过期后需重新登录。首次登录后绑定账号，其他 AutoDL 账号使用另一个邀请码及独立环境。

```bash
bash ./fo accounts   # 已保存账号
bash ./fo switch     # 切换独立账号连接
bash ./fo doctor     # 查看服务器后端及登录状态
```

## HTTP 菜单

| 输入 | 功能 |
|---|---|
| 1 | 实例列表 |
| 2 / 3 | 地区空闲库存 / GPU 型号 |
| 4 | AutoPanel 文件与传输管理 |
| 5 | 实例详情、连接信息、监控、开关机、重启、定时关机及取消、重命名、保存系统盘镜像、释放实例 |
| 6 | 我的镜像：列表、进度、重命名、删除或移除 |

实例管理先选择实例，再逐步填写参数，最后输入 `yes` 执行、`no` 取消。开机读取实时计算时价与扩容数据盘日价，并显示总计折合时价；确认前报价或实例状态变化会要求重新确认。当前开机报价支持按量计费且未扩容系统盘的实例，其他配置请暂用网页。确认两分钟有效且只能使用一次；提交响应中断时先刷新状态，程序不会自动重试。

连接信息默认只显示 SSH 地址、端口与命令；选择显示 SSH 密码时才返回密码。释放实例会永久删除系统盘和数据盘，保存镜像只包含系统盘。子账号实际可执行的操作由 AutoDL 授权决定。

### AutoPanel 菜单

选择已运行实例后，隐藏输入其独立访问密码：

| 输入 | 功能 |
|---|---|
| 1 / 10 | 查询实例目录 / 按编号逐级浏览实例目录 |
| 2 | 浏览已授权网盘目录 |
| 3 / 4 | 传输队列 / 历史记录 |
| 5 | 实例文件或整个目录上传至阿里云盘 |
| 6 | 阿里云盘文件或整个目录下载至实例 |
| 7 | 跟踪当前队列，显示进度及终端、本地桌面结果提醒 |
| 8 | 取消等待或进行中的传输任务 |
| 9 | 清理已成功的传输记录，保留文件 |
| p / q | 重新登录 AutoPanel / 返回 |

上传输入实例文件或目录的绝对路径，浏览网盘到目标目录后输入 `s`。下载时输入文件编号；下载整个目录用 `d 编号`，普通目录编号用于进入目录。下载位置使用 AutoPanel 默认工作目录，通常为 `/root/autodl-tmp`。核对方向、路径及是否递归，输入 `yes/no`；发现同名目标则拒绝提交。

传输支持已授权阿里云盘资源库和备份盘。单文件资源库此前完成过真实 256 KiB 往返和 SHA-256 校验；目录传输依据网页接口通过测试服务验证，备份盘、大文件与大目录尚未真实实测，目录数量等限制以平台为准。其他网盘当前支持目录浏览，传输仍需网页。新授权网盘仍在网页完成。

输入 7 跟踪当前队列，每 5 秒读取一次真实任务状态；完成、失败或取消后在终端和本地桌面提醒。`Ctrl+C` 停止本地跟踪并返回菜单，已提交的服务器传输继续运行。提醒需要本地终端运行并联网；离线期间完成的结果重新连接后通过历史记录查看。Linux 桌面提醒需要 `notify-send`，WSL 需自行配置；通知通道不可用时保留终端结果。

完整范围、接口来源与验证边界见 [功能清单](docs/features.md)。

## 管理员与开发

已有 SSH 邀请注册仍使用 `fo-admin invite-code`。HTTP 服务按独立 Linux 用户和私有 Unix socket 隔离，服务器管理员可管理这些环境。常规结果移除连接密码和授权凭据；只有用户主动选择显示 SSH 密码时返回该实例密码。Jupyter Token、网盘授权 Token 和签名下载链接保留在实际请求端。

- [服务器说明](docs/server.md)
- [首次使用](docs/quickstart.md)
- [旧 Fo 文档（历史兼容）](docs/legacy-fo.md)

原生模块位于 `native/`。可直接运行 `node native/cli.mjs` 在本机请求 AutoDL，或 `node native/cli.mjs --remote 配置.json` 使用服务器。旧 Fo 适配代码保留用于审查和迁移，不在 HTTP 服务中执行。

```bash
npm test
npm run test:native
npm run test:terminal
```

接口取自 AutoDL 公开网页及 AutoPanel 前端，没有官方开放 API 的稳定性承诺；平台变更可能需要更新。
